# 角色與 Agent Skill 初版

角色能力是具名 Scope 集合，用來分配權限；Agent Skill 是既有 serviceRegistry 的任務能力。本版沿用角色，不新增角色資料表或第二套授權。

## 操作

1. 後台進入租戶 → 權限 →「角色能力」。
2. 新增角色或使用「一般員工」「報告分析員」範本，調整名稱與能力。
3. 一般員工範本不預授任何表單或知識標籤，請另外選擇；範本僅使用目前可授予的能力。
4. 按「完成」，再指派部門或帳號，最後按權限頁的「儲存」。編輯草稿不會自行授權。
5. 前台對話上方展開「我的助理能力」。權限修改後按「重新整理能力」，即可查看最新角色與可用任務能力；在原對話輸入需求執行。

## 授權語意與範圍

- 部門／帳號角色與租戶、部門、帳號的其他 Scope 授權取聯集。移除角色不會撤銷其他來源的授權。
- 角色名稱不會增加主管查團隊、簽核或跨部門資料權限；這些仍需各業務工具實作並驗證。
- 前台 Skill 清單沿用 serviceRegistry.enabledFor 與使用者可見意圖；未授權任何表單時不顯示填表能力。
- 清單只提供能力摘要，不公開其他人的角色、Scope 或憑證；操作仍走原對話服務與工具權限檢查。
- 本版未新增可編輯 Skill 執行指引、SKILL.md 匯入或新的流程引擎，Skill 仍由既有服務實作。
- 不需要資料庫 migration。既有角色資料保持相容。

## API

`GET /api/skills`，需使用者 JWT，租戶依既有 API Key 解析；不接受 query/header 指定其他使用者。回傳 `{ data: { roles, skills } }`，設置 `Cache-Control: no-store`，不消耗 LLM 配額。
