# 門市小幫手 Demo 檢查清單

## 事前準備

- [ ] 後端啟動，`OPENAI_API_KEY`、`MCP_SIGNING_KEY` 已設定；`ANTHROPIC_API_KEY`（或其他 LLM）可用。
- [ ] 門市 Demo 服務啟動，`PUBLIC_BASE_URL` 為平板連得到的位址；後台已註冊並重新整理工具清單（應有 7 個工具）。
- [ ] 店員帳號已授權 `service:agent`、`mcp:store-demo`。
- [ ] 知識庫已匯入設備手冊（含咖啡機紅燈處理）與門市作業 SOP。
- [ ] 平板（iPad、Android 各一）已裝 Expo Go，與後端在同一個網路；App 已登入。
- [ ] 準備一排貨架（或貨架照片）、一張有條碼的優惠券（券號 COFFEE50）。

## 情境

| # | 操作 | 預期 |
|---|---|---|
| 1 | 首頁按「語音對話」，說「幫我查御飯糰的庫存」，按「結束對話」 | 對話出現文字、庫存表格；朗讀開時唸出一兩句重點 |
| 2 | 首頁按「拍照問 AI」，拍貨架 | 結果頁框出缺貨／即期／擺放錯誤，右側分組清單 |
| 2 | 按「建立補貨單（N 項）」→ 改數量、取消一項 → 確認 | 彈窗關閉，對話出現「已完成」；任務分頁紅點 +1 |
| 3 | 首頁點「今日重點 → 商品庫存偏低」 | 自動問「哪些商品庫存偏低？」並出現表格 |
| 3 | 說或打「幫我建立補貨單」→ 確認 | 跳出補貨確認彈窗；完成後在任務分頁看到新單 |
| 4 | 首頁點「今日重點 → 設備異常」 | 自動問「咖啡機紅燈閃爍怎麼處理？」，依知識庫回答並附來源 |
| 5 | 常用情境「促銷活動查詢」、「會員活動」 | 活動表格；會員活動只列會員類 |
| 5 | 相機切「優惠券」拍券 | 優惠券結果頁顯示「可使用」與條件；按「問 AI」轉到對話 |
| 5 | 相機切「掃條碼」掃券 | 直接跳到優惠券結果頁（只查一次） |

## 現場出狀況時

- 語音辨識不準：改用打字，或按「鍵盤輸入」。
- 拍照辨識失敗：再拍一張；優惠券改用掃條碼。
- 確認彈窗顯示逾時：關閉後重新要求建立補貨單。
- 商品圖不顯示：檢查門市服務的 `PUBLIC_BASE_URL` 是否為平板連得到的位址。
- 連不上伺服器：登入頁「伺服器設定」確認位址（在「我的」改伺服器會登出，需重新登入）。
