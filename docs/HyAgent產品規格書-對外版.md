本文件說明 HyAgent 目前可提供的產品能力與使用條件。個案啟用功能、客製整合、部署規模、交付項目與服務水準，於導入時依雙方確認的專案範圍訂定。

## 1. 產品概述

HyAgent 將 AI 對話、企業知識與業務操作整合於同一個服務入口。使用者可透過自然語言查詢資料、填寫表單、產生報告，並在確認後執行已授權的外部系統操作。

平台可獨立使用，或嵌入企業入口網站與既有服務網站；亦可依品牌與業務情境規劃行動應用。管理者可集中設定服務、知識可見範圍、表單與外觀，並查看用量、使用者回饋與操作紀錄。

### 1.1 適用情境

| 情境 | 使用方式 |
|---|---|
| 企業知識助理 | 查詢規章、作業說明與已匯入的企業文件 |
| 業務申請助理 | 透過對話補齊欄位、檢查資料並確認送出 |
| 文件彙整助理 | 依授權知識內容產生主題報告與可下載文件 |
| 外部系統操作助理 | 查詢或執行已完成串接的業務工具 |
| 品牌服務入口 | 在既有網站或行動應用提供品牌化的 AI 互動體驗 |

### 1.2 功能提供方式

本文件中的功能依下列方式導入；分類描述啟用條件，不代表固定的商業方案或授權組合。

| 提供方式 | 說明 | 代表項目 |
|---|---|---|
| 平台功能 | 由平台提供，依服務與權限設定啟用 | 對話、表單、知識管理、任務、站內通知、回覆評價、管理後台 |
| 配合服務啟用 | 需具備對應模型、基礎設施或外部服務 | 知識檢索、報告產生、PDF 輸出、語音、郵件寄送 |
| 專案整合 | 需確認介面、資料、權限與測試環境 | 單一登入、正式表單送出、MCP 工具、品牌行動應用與影像情境 |

## 2. 使用者與管理角色

| 使用對象 | 主要能力 |
|---|---|
| 一般使用者 | 使用被授權的 AI 服務、辦理表單、查詢知識、查看個人任務與報告、提供回覆評價 |
| 租戶管理作業人員 | 管理所屬組織的設定、使用者、權限、表單、知識、回饋與營運資訊 |
| 平台管理作業人員 | 管理租戶、平台服務、外部工具與平台層操作紀錄 |
| 系統整合人員 | 配合網站嵌入、身分串接、業務介面及事件通知整合 |

實際管理帳號的登入與可操作範圍於導入時確認；上述角色用於說明作業分工，不代表預設提供各層獨立的管理登入機制。

## 3. 使用者功能規格

### 3.1 AI 對話與任務處理

- 以繁體中文為主要互動語言，依使用者需求分流至可用的表單、知識問答、報告或外部工具服務。
- 支援多輪對話，保留目前任務已收集的資料，逐步追問缺少資訊。
- 服務使用受到組織設定與使用者權限限制。
- 可停止目前的 AI 查詢；已完成的外部操作不會因停止查詢而撤回。
- 寄信、送單及其他需確認的操作，先呈現內容供使用者確認，再執行動作。

### 3.2 對話式表單

| 功能 | 規格說明 |
|---|---|
| 欄位填寫 | 從對話整理欄位，逐步補齊缺漏資訊，並提供表單畫面供人工修正 |
| 欄位型態 | 支援文字、數字、多行文字、選項、日期、時間、勾選與附件等欄位 |
| 資料檢查 | 依表單定義檢查必填、格式與已設定的跨欄位規則 |
| 送出確認 | 完成摘要檢視與明確確認後，才執行送出 |
| 同意事項 | 明確同意欄位由使用者主動操作 |
| 附件 | 單檔上限 10 MB；外部系統接收方式需於串接時確認 |
| 表單管理 | 管理端可建立、編輯、匯出及調整表單版型 |
| 範例表單 | 提供請假、國內出差報銷與外出登記等參考情境 |

新增表單與串接外部系統分別確認。表單可依平台支援的欄位與規則設定；正式送出仍需完成目標系統的介面、欄位對應與結果驗證。

### 3.3 企業知識問答

- 以企業提供的網站或文件建立知識索引，透過語意檢索輔助回答。
- 依登入者權限篩選可見內容，問答與報告沿用相同的知識可見範圍。
- 支援建議問題，協助使用者開始查詢。
- 查無適當資料時提示資訊不足，避免將缺乏來源的內容當作企業規定。
- 回答品質取決於來源內容、更新頻率、文件可解析程度與所用模型；重要業務判斷仍應核對原始資料。

### 3.4 報告產生與下載

- 由對話提出主題，背景產生報告並顯示進度。
- 依授權知識內容分章彙整；無資料章節予以標示，全部無資料時不產生報告檔案。
- 資料符合結構化計算條件時，可產生對應數據圖表。
- 提供 Markdown 與 HTML；PDF 需部署環境具備可用的瀏覽器列印元件。
- 使用者可查閱與下載自己的報告，管理端可查詢租戶內報告。
- 報告預設保存 30 天，可於部署時調整；同一租戶同時間處理一份報告。

### 3.5 我的任務與站內通知

- 我的任務彙整未完成表單、已送申請及個人報告。
- 支援續填已保存的草稿與取消可取消的任務；尚未保存的畫面編輯不屬於可還原資料。
- 站內通知涵蓋符合條件的未完成草稿、表單待確認／送出結果及報告結果。
- 提供未讀數、全部／未讀篩選、標為已讀及任務跳轉。
- 通知顯示目前可用的任務狀態，最多 100 則；不作為永久事件歷史。

### 3.6 回覆品質回饋

- 使用者可對支援評價的 AI 回覆給予讚或倒讚，並可改評或撤回。
- 倒讚可附原因與說明，協助管理者了解資料錯誤、未回答問題或資訊過時等情況。
- 管理端可查看問答快照、可用作答依據、統計與處理狀態，並記錄處理說明。
- 評價資料預設保存 180 天，可依部署設定調整。
- 回饋供人工品質改善與追蹤使用，不會自動重新訓練模型或修改企業知識。

| 模組 | 管理內容 |
|---|---|

| 使用者與權限 | 使用者資料、部門／帳號授權、角色技能組合與服務存取範圍 |
| 身分串接 | 單一登入設定、公鑰輪替、撤銷與相關登入狀態管理 |
| 品牌外觀 | AI 名稱、Logo、歡迎語、主色、主題與嵌入元件位置 |
| 表單 | 表單定義、欄位、規則、版型與匯出 |
| 知識庫 | 網站來源、檔案上傳、資料夾批次匯入、索引工作、刪除、可見性標籤與查詢測試 |
| 外部工具 | MCP 服務登記、適用租戶、工具啟停、確認要求及唯讀核准 |

| 回覆評價 | 評價清單、統計、原因分析與處理狀態 |
| 用量與報告 | 對話、訊息、送出與模型使用資訊，以及報告查詢與下載 |
| 稽核紀錄 | 重要管理異動、具副作用的工具操作與相關下載事件 |

## 5. 整合能力

| 整合方式 | 產品能力 | 導入條件 |
|---|---|---|
| 網站嵌入元件 | 在既有網站加入 AI 對話介面，可控制開關並接收送出結果事件 | 確認宿主網站、嵌入來源及身分處理方式 |
| SDK／API | 提供程式介面，支援客製前端與宿主控制 | 依介面文件進行開發與授權驗證 |
| 單一登入（SSO） | 將宿主網站已驗證的使用者身分帶入平台，免重複輸入帳密 | 宿主後端配合身分簽發，並完成登入、登出、換人與金鑰管理測試 |
| 訪客模式 | 可由租戶開放公開服務，提供獨立訪客身分 | 明確開啟並設定訪客服務與資料權限 |
| 表單送出介面 | 以 HTTP 介面與欄位對應方式連接業務系統 | 提供正式／測試端點、認證與回傳規格；目前沿用既有 OA 送出契約 |
| MCP 外部工具 | 透過 Model Context Protocol 接入查詢與操作工具 | 提供相容服務、工具定義、授權規則與測試資料 |
| 事件回呼（Webhook） | 表單成功送出後投遞具簽章的事件，失敗時自動重試 | 接收端實作簽章驗證與重複事件處理 |
| 郵件服務 | 由 AI 協助擬稿，使用者確認後透過郵件服務寄送 | 配置可用的 SMTP 服務、寄件者與認證 |

ERP、CRM、HR、ITSM 等系統可作為整合目標，實際可用操作須經介面評估與專案串接。外部工具由平台設定授權；免確認的唯讀工具需經管理者核准，工具定義變更後須重新確認核准狀態。

## 6. 行動、語音與影像應用

| 能力 | 說明與提供條件 |
|---|---|
| 品牌行動應用 | 可運用既有共用能力建立品牌對話入口；畫面、業務流程、支援裝置與發布方式依專案確認 |
| 行動對話 | 提供登入或經授權的訪客使用、AI 對話、回覆評價與操作確認等共用能力 |
| 語音輸入與朗讀 | 行動端支援語音轉文字與回覆朗讀；轉文字需配置對應雲端模型服務，朗讀依裝置能力提供 |
| 影像情境 | 可配合特定業務流程分析影像並查詢外部資料；模型、工具、資料來源與辨識驗收條件需個別確認 |

目前品牌與門市等情境範例供導入評估使用。正式資料串接、應用商店發布與裝置驗證列入個案交付範圍。

## 7. 資料與安全管理

| 面向 | 提供能力 |
|---|---|
| 組織隔離 | 以租戶區分資料與設定，並於服務端檢查存取權限 |
| 服務授權 | 依部門、帳號或角色技能組合配置可用服務 |
| 知識可見性 | 文件標籤搭配使用者授權，限制問答與報告可檢索範圍 |
| 登入管理 | 支援正式身分串接、登入狀態到期、登出及相關撤銷機制 |
| 金鑰保護 | 提供敏感設定遮罩、指定敏感資料的儲存加密，以及 SSO 公鑰輪替與撤銷 |
| 操作確認 | 表單送出、寄信與需確認的外部操作先經使用者確認 |
| 外部內容處理 | 對檢索與工具內容設置處理邊界，並限制不安全連結及部分外部內容載入 |
| 用量控制 | 提供請求頻率限制與模型用量配額機制 |
| 操作追蹤 | 記錄重要設定變更與業務操作，供管理與問題調查使用 |

回覆評價會保存當時問答內容與可用診斷資訊，導入時應一併確認可閱人員及保留期間。模型與外部服務的資料處理範圍，應按實際啟用功能與供應商配置確認。

## 8. 部署與模型選擇

平台包含使用者前台、管理後台與應用服務，可依企業環境規劃於雲端或企業自有環境部署。正式環境需配置資料庫、持久化儲存、網域、HTTPS 與所需模型服務；備份、監控、網路連通及維運責任於部署規劃時確認。

| 項目 | 支援方式與條件 |
|---|---|
| 雲端模型 | 支援 Anthropic 與 OpenAI；可配置租戶自有金鑰與模型 |
| 地端模型 | 支援相容介面的自架語言模型與向量模型，需驗證所選模型的工具呼叫、輸出品質與效能 |
| 資料庫 | 正式環境以持久化資料庫保存所支援的業務資料 |
| 報告 PDF | 需具備可用的瀏覽器列印環境 |
| 容量規劃 | 依租戶、使用量、文件量、模型與整合服務評估資源及併發能力 |

選用地端模型時，仍需逐項確認語音、嵌入來源、外部工具與其他服務的連線需求；完整離線運作與資料留存範圍應以實際部署驗證。擴充至多個服務實例、高可用或災難復原，需另行規劃與驗證。

## 9. 現行使用限制

| 項目 | 範圍說明 |
|---|---|
| 正式業務結果 | 展示資料與模擬送出不具正式申請或簽核效力；正式結果以完成整合的外部系統為準 |
| 簽核進度 | 現有示範進度不代表已接收正式簽核事件；正式追蹤需另外串接 |
| 外部整合設定 | 尚未提供可在管理端自行設定任意系統、集中管理各式認證並完成通用串接的完整功能 |
| 通知通道 | 目前通知中心提供站內通知；電子郵件通知、瀏覽器推播與通知偏好需另行評估 |
| 背景工作 | 報告工作中斷後的自動恢復與全面跨實例同步未列為現行能力 |
| 效能與服務水準 | 回應時間受模型、資料量及外部服務影響；可用率、固定併發量與處理時間依個案測試及約定 |
| 行動與影像 | 依已完成的品牌與業務情境提供，不代表任意裝置、任意影像或任意業務皆已支援 |

## 10. 導入準備與交付範圍

### 10.1 客戶準備事項

1. 確認優先使用情境、目標使用者、管理分工及可用服務。
2. 提供可使用的知識內容、資料權利、機密分級與部門／帳號授權規則。
3. 提供宿主網站、身分來源，以及業務系統的測試環境與介面資料。
4. 確認部署位置、模型選擇、對外連線、資料保存與維運需求。
5. 提供品牌素材、代表性問題、表單案例及預期結果，作為測試與驗收依據。

### 10.2 專案交付確認

| 交付面向 | 需確認內容 |
|---|---|
| 平台啟用 | 租戶、使用者前台、管理入口與啟用模組 |
| 初始設定 | 品牌外觀、服務、權限與資料保存設定 |
| 表單與知識 | 表單數量與規則、知識來源、匯入範圍及更新責任 |
| 外部整合 | 系統名稱、可用操作、欄位對應、認證與錯誤處理方式 |
| 行動及其他情境 | App 畫面、支援裝置、語音／影像與發布項目 |
| 文件與移交 | 操作說明、已選用介面的整合文件、管理交接及教育訓練範圍 |
| 維運服務 | 模型費用、基礎設施、備份、監控、事件處理與服務水準 |

## 11. 驗收項目

以下作為驗收清單基礎，依已選用功能建立測試案例與通過條件。

| 項目 | 驗收重點 |
|---|---|
| 入口與身分 | 指定網站或入口可正常使用；SSO、登出、換人及訪客模式符合約定 |
| 表單辦理 | 完成欄位收集、人工修改、規則檢查、摘要確認與送出結果驗證 |
| 知識問答 | 以約定問題集檢查回答、無資料處理與不同帳號的可見範圍 |
| 報告 | 產生約定主題、顯示進度、下載已啟用格式，並限制存取範圍 |
| 外部工具 | 授權查詢可執行；需確認操作在確認前不得執行；結果與外部系統一致 |
| 任務與通知 | 個人任務可正確查閱、續填與跳轉，通知已讀不影響其他帳號 |
| 回覆評價 | 使用者可評價與撤回，管理者可查詢統計並記錄處理結果 |
| 管理與稽核 | 已選用設定可操作，重要異動與操作結果可查閱 |
| 行動與擴充 | 依約定裝置、模型與情境驗證語音、影像及 App 流程 |
| 部署與容量 | 以約定資料量與負載測試權限隔離、錯誤處理及效能 |
