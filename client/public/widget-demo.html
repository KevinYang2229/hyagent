這是一個「別人的網站」

這個頁面模擬第三方網站。它本身與 OA 系統無關，只在頁尾加入了一行 widget 載入碼，右下角就會出現浮動按鈕；點擊後彈出聊天視窗即可串接後端 AI。

最簡接入（對方只需貼這一行，落到預設租戶，向後相容）。 src 一律是 HyAgent 自己的網域—— widget 與面板都由 HyAgent 託管，整合方不需要代管任何檔案：

<script src="https://hyagent.example.com/sdk/widget.js"></script>

產品化接入（多租戶、預選表單、語言、外觀、SSO）：

<script src="https://hyagent.example.com/sdk/widget.js" data-title="客服小幫手" data-key="pk_xxxxx" data-form="leave-request" data-locale="zh-Hant" data-theme="light" data-position="right" data-token-url="/your/token-endpoint"></script>

宿主頁可監聽事件、或程式化控制：

// 監聽「表單已送出」 window.addEventListener('oa-agent:submitted', function (e) { console.log('已送出', e.detail.submission); }); // 程式化開關 OAAgent.open(); OAAgent.close(); OAAgent.toggle(); // 放大／還原（放大時面板置中撐大並蓋上背景遮罩） OAAgent.expand(); OAAgent.collapse(); // 使用者登出宿主網站時（有用 data-token-url 就必做）： 先等面板作廢 Session 再導頁 await OAAgent.logout();
