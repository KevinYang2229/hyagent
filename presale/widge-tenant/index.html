⚡ 一行嵌入

<script src=".../sdk/widget.js"> 貼上即用，純 JS、零依賴、不必打包。

💬 浮動按鈕

右下角小幫手，點擊彈出聊天室；不干擾原頁面排版。

🔐 SSO 免登入

帶 data-token-url 指向你家的 Identity Endpoint，沿用宿主登入身分，使用者免再登入。

🎨 可設定外觀

data-title / data-theme / data-locale / data-position 調整文案、亮暗、語言、左右。

🛡️ 樣式隔離

聊天介面跑在 iframe 內，scoped 樣式不污染宿主頁，不會被你的 CSS 影響。

🧩 事件可監聽

送出等事件以 oa-agent:submitted 派發，宿主頁可接手後續流程。

怎麼接？三步

  1. 跟我們申請租戶，拿到 Tenant ID 與公開金鑰 pk_…； 你自己產一組金鑰對，把公鑰交給我們登記。 私鑰留在你的環境，我們不持有。
  2. 你的後端開一支 Identity Endpoint，用你自己的私鑰現簽一張短效憑證， widget 需要時才來取（data-token-url）。
  3. 在頁面貼上載入碼：
    <script src="https://hyagent.example.com/sdk/widget.js" data-key="pk_…" data-token-url="/api/mybot/identity"></script>

src 用我們提供給你的 HyAgent 網域—— widget 與聊天面板都由我們託管，你不需要自行部署或代管任何檔案； 要換成你自己網域的只有 data-key 與 data-token-url。
