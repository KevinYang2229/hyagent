登入 Beta Cloud

模擬客戶系統自家的登入頁。選一位使用者，之後 /api/mybot/identity 就以這個 Session 的身分簽 Assertion，登出之後一律回 401—— 身分一律由後端的登入狀態決定，前端傳什麼都不算（規格 §5.2）。

登入後開「線上客服」，按 F12 看 console：[sdk-custom-ui] 那幾行會印出簽出來的 claims 與 HyAgent 最終認定的登入者。再按右上「登出」：頁面會先 await oa.logout() 請 HyAgent 作廢 Session，再送出本站的登出表單（整合手冊 §5.3）；換另一位登入，console 的登入者要跟著換。
